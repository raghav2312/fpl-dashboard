# Fantasy Premier League Dashboard

## Overview
Built an end-to-end FPL analytics dashboard using Python, Pandas, Streamlit, and Plotly to analyze season performance, overall rank progression, and gameweek-level insights.

## Features
- Overall rank tracking
- Rank movement analysis
- Gameweek points visualization
- Team value monitoring
- Automated FPL API ingestion pipeline

## Architecture
FPL API → Raw JSON → Transformation Layer → Processed CSV → Streamlit Dashboard

## Tech Stack
- Python
- Pandas
- Streamlit
- Plotly
- Requests
